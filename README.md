# Web Studio — 3D / Hologram Landing + CMS

Одностраничный сайт на чистом HTML, CSS и JavaScript с отдельной админ-панелью для редактирования контента.

## Что реализовано

- тёмно-красная премиальная палитра;
- CSS 3D-голограмма в hero-блоке;
- перспективная сетка, частицы, scanlines и reveal-анимации;
- адаптивность 320px–1920px и `prefers-reduced-motion`;
- блок «Наше портфолио» с редактируемыми карточками;
- рекламный баннер с красивой inline CTA-кнопкой;
- отдельная `admin.html` для управления контентом;
- редактирование hero, «О нас», аудитории, цен, расчёта стоимости, блока «Почему мы», контактов и подвала;
- добавление/удаление карточек преимуществ, сегментов аудитории, проектов, тарифов, услуг и пунктов расчёта;
- включение/выключение портфолио и рекламного баннера;
- импорт/экспорт CMS-контента в JSON;
- сброс к исходному контенту;
- клиентская валидация формы заявки.

## Структура

- `index.html` — публичная страница;
- `styles.css` — стили сайта;
- `script.js` — интерактив и форма;
- `content.js` — модель контента и CMS-рендеринг;
- `admin.html` — админ-панель;
- `admin.css` — стили админ-панели;
- `admin.js` — логика редактора.

## Запуск

Рекомендуется запускать через локальный HTTP-сервер, чтобы `index.html` и `admin.html` работали в одном origin.

### Python

```bash
python -m http.server 8000
```

или:

```bash
python3 -m http.server 8000
```

Откройте сайт:

```text
http://localhost:8000/
```

Админ-панель:

```text
http://localhost:8000/admin.html
```

## Как пользоваться админ-панелью

1. Откройте `admin.html`.
2. Выберите блок в меню слева.
3. Измените тексты, цены, ссылки, карточки или видимость секций.
4. Нажмите **«Сохранить»**.
5. Обновите открытую страницу сайта — изменения подхватятся автоматически из CMS-хранилища.

Контент можно экспортировать в JSON и затем импортировать обратно.

## Важно про хранение данных

Текущая версия проекта остаётся статической: админ-панель хранит изменения в `localStorage` браузера. Это удобно для прототипа, демонстрации и локального редактирования, но изменения не синхронизируются между разными браузерами/устройствами и не становятся глобальными для всех посетителей сайта.

Для полноценной production-админки нужно подключить backend/API и базу данных (или CMS), а также авторизацию администратора. `content.js` уже отделяет данные от верстки, поэтому серверное хранилище можно подключить без переделки дизайна.

## Что заменить перед публикацией

Через админ-панель замените реальные данные:

1. Telegram и ссылку на Telegram.
2. Телефон.
3. Домен.
4. Название студии.
5. Портфолио и ссылки на кейсы.
6. Цены и сроки.
7. Текст рекламного баннера.

Дополнительно перед production-запуском подключите реальный обработчик формы заявки: backend, CRM, webhook или Telegram Bot API через сервер.
